# Document and acceptance audit

Compare the exact candidate with requirements and validated scope. Inspect relevant facts, citations, local links, consumers, and package resources. Run available documentation/package validators and actual-resource checks when in scope. Preserve the candidate; recommendations are for its production owner.

For setup, assess declarations against supplied repository facts, requested choices, and existing restrictions. Use read-only evidence; never probe an external write, branch, commit, or PR to validate configuration. Missing access limits the affected claim. One adequate final verdict suffices; request separate executable QA only for evidence beyond this scope.
