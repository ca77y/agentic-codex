# Independent research branches

Read before dispatching independent research children, or when acting as one.

Fan out only for at least two independent subquestions, dispatched as a batch within available slots. Size alone does not justify delegation. Keep dependent questions together; if nested dispatch is unavailable, research them directly.

Give each `ca77y_library_researcher` the absolute project path, bounded question, available library baseline, required research tools, source constraints, and this child contract. Use the model/context settings in the core skill. The parent owns integration.

## Child contract

Search local knowledge as needed, research the assigned question, and batch durable evidence through raw-note-only scribes. Give concurrent scribes disjoint new-note paths; serialize updates to existing notes. Never dispatch full ingest or clerk fixes, or write wiki/shared metadata. If no scribe slot is available, return the complete provenance-bearing payload for the parent to persist later.

Return synthesis, citations, unresolved contradictions, retrieval limits with subject queries and paths, every persisted raw-note path, and any unpersisted payload. Forward descendants' paths and uncertainty too. Stop at the bounded question; do not run the parent's final ingestion/audit workflow.

## Parent integration

Collect every child result and outstanding write. Persist deferred payloads, then send one complete path list and reconciled synthesis to a serialized full-ingest scribe. Do not rediscover the list by scanning `library/raw/`. Preserve source limitations unless actual subject evidence resolves them. Run the normal changed-scope audit after ingestion.
